Expense Tracker - Final Setup Guide

1. Open XAMPP and start Apache & MySQL.
2. Visit http://localhost/phpmyadmin and create a DB: 'financetracker'.
3. Import 'financetracker.sql' from the project root.
4. Open terminal in the 'backend' folder and run: node index.js
5. Open 'frontend/loginPage/index.html' via Live Server.
6. Register a user, login, and add transactions — all data is saved in MySQL.
